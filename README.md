Clinician-friendly, GitHub Pages-ready single-page interview website.

## Files
- `index.html` — main website
- `style.css` — visual system and responsive layout
- `script.js` — subtle scroll reveals + patient journey interaction
- `hero-patient.png` — cinematic patient hero image
- `visual-aid-clinician.svg` — clinician visual aid
- `lbl-clinical-evidence.svg` — clinical evidence LBL

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder into the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save. GitHub will publish the site.

## Scientific / promotional note
The site separates Rusan public product information from published apomorphine evidence. The Dewey trial is molecule/class evidence and is not represented as an APOSAN-specific trial. Verify the current local approved PI, exact promotional claims, safety information, device instructions, and internal MLR requirements before any real-world promotional use.
